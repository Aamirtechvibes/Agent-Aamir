## What is Agent Aamir?

**Agent Aamir** is an AI-powered development assistant that acts as your coding partner. Think of it as a smart colleague who can read, write, and modify code based on your instructions—but with an important safety feature: **it shows you what it's going to do before actually doing it**.

- "Create a todo list app" → It scaffolds the entire project
- "Add a login page to my React app" → It creates the necessary files
- "Find all API endpoints in my codebase" → It searches and lists them
